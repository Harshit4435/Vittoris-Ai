# VITTORIS — AI-Powered Growth & AI Services Platform

> **AI-Powered Growth and AI Services for Modern Businesses.**  
> A luxury enterprise platform uniting performance-based client acquisition with bespoke AI operational infrastructure, inspired by high-end editorial aesthetics and kinetic motion design.

---

## 🌟 Overview & Purpose

**Vittoris** is an outcome-driven growth and AI services company engineered for one clear objective: generating pre-qualified client pipeline while eliminating the operational drag of chasing cold leads.

- **10 Core Service Architectures**: Pay-per-appointment pipelines, conversational voice & chat setters, document intelligence, custom AI agents, and workflow automations.
- **8 Commercial Outcome Solutions**: Pre-vetted high-ticket appointments, 24/7 sub-minute response engines, automated proposal generation, and cross-platform synchronization.
- **6 Industry Blueprints**: Accounting, legal, real estate, healthcare, B2B SaaS, and financial advisory verticals.
- **Strict Performance Alignment**: Verified decision-maker qualification criteria defined in writing prior to launch. Unqualified bookings carry zero billing cost.

---

## ⚡ Key Highlights & Features

- **Editorial Luxury Design System**: Deep obsidian matte black (`#0B0B0B`), Champagne Gold (`#C7A86D`, `#E5C788`, `#A38347`), and frosted glass panels (`rgba(17, 17, 17, 0.72)`).
- **Kinetic Typography & Motion**: *Playfair Display* editorial serif paired with *Manrope* sans-serif, **Lenis** inertia scrolling, and micro-hover transitions.
- **Autonomous Pipeline Architecture Console**: Full visibility across acquisition, screening, calendar synchronization, and show-up protection.
- **Complete 10-Service Directory (`/services`)**: Filterable by `Client Acquisition`, `Custom AI & Infrastructure`, `Autonomous Agents`, and `Operations & Growth`.
- **Deep Architecture Blueprints (`/services/:slug`)**: Ingestion topology, AI processing layers, system sync, and contractual qualification metrics.
- **Direct Discovery Call Scheduler**: Interactive modal with custom calendar slot selection and project qualification scoping.

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/) + [Vite](https://vite.dev/)
- **Routing**: [React Router DOM v7](https://reactrouter.com/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/) with `@tailwindcss/vite`
- **Smooth Scrolling**: [Lenis](https://lenis.darkroom.engineering/)
- **Motion & UI**: [Framer Motion](https://www.framer.com/motion/) + [Lucide React](https://lucide.dev/)
- **Language**: TypeScript

## 🚀 Quick Start

### 1. Clone the repository
```bash
git clone https://github.com/Harshit4435/Vittoris-Ai.git
cd Vittoris-Ai
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start local development server
```bash
npm run dev
```

### 4. Build for Production
```bash
npm run build
```
